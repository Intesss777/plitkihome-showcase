# PLITKIHOME

Демонстрационный сайт салона керамогранита. Самостоятельный проект полного цикла:
от идеи и структуры до интерактивных функций, визуальной доработки и публикации.

## Возможности

- каталог плитки с фильтрами по стране, фактуре и назначению;
- калькулятор стоимости проекта;
- витрина реализованных интерьеров;
- интерактивная примерочная плитки;
- адаптивная навигация и контактные действия.

## Технологии

- HTML;
- CSS;
- JavaScript;
- адаптивная вёрстка;
- Vercel для публикации.

## Демо

https://plitkihome1.vercel.app/

## Локальный запуск

Откройте `index.html` в браузере или запустите любой локальный статический сервер.
